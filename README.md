# Movie Finder

Aplicación **SPA** con **Vite** y JavaScript vanilla para buscar películas, ver sus detalles, reparto, tráilers y guardar favoritos.

## Funcionalidades
- Inicio con secciones de películas
- Búsqueda
- Detalle de película con reparto (créditos) y video
- Favoritos
- Página de error para rutas no encontradas

## Estructura
- `src/api/`: cliente y llamadas a la API de películas (la configuración está en `src/api/config.js`)
- `src/pages/`, `src/components/`: vistas y componentes
- `src/routes/`: router propio sin framework

## Cómo ejecutar
```bash
npm install
npm run dev
```

## Proyecto de aprendizaje
Práctica de SPA sin framework, consumo de API y componentes en JavaScript.
